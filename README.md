# 打工人康复指南

面向普通劳动者的体态与工作习惯科普小游戏。通过观察工作场景、选择行动和阅读学习卡，理解身体负担与常见健身误区，而不是靠两次点击“治好体态”。

## 十关试玩

| 关卡 | 场景 | 学习重点 |
| --- | --- | --- |
| 01 键盘侠的觉醒 | 伏案与肩部向前 | 胸前活动、肩胛控制与工作习惯；不把圆肩等同于胸紧背弱 |
| 02 久坐暂停键 | 持续坐着、盯屏 | 改变姿势与视线距离是两种不同的休息 |
| 03 理发师的肩颈松一松 | 连续抬手、低头后的肩颈与肩胛周围酸累 | 轻柔颈侧伸展、靠墙软球放松 |
| 04 收银员的小腿与足底 | 久站后的小腿与足弓紧绷感 | 小腿泡沫轴、坐姿足底软球 |
| 05 搬运工的臀髋小课堂 | 搬运后的臀部酸累与髋部发力认识 | 臀部泡沫轴、徒手髋铰链 |
| 06 蝴蝶背，不是健康勋章 | 摄影师认识肩胛运动 | 靠墙推撑、轻阻力划船；不凭照片诊断翼状肩胛 |
| 07 直角肩，先别消灭斜方肌 | 导购抬手整理衣架 | 颈侧舒适活动、支撑滑墙；斜方肌有正常功能 |
| 08 翘臀，不靠把腰顶出去 | 舞台工作人员学髋部控制 | 徒手臀桥、髋铰链；不靠过度拱腰追求外形 |
| 09 练腹，就能定点瘦肚子？ | 分拣员刷到瘦腰挑战 | 对侧鸟狗、步行；局部训练不保证定点减脂 |
| 10 酸痛，不是训练成绩单 | 咖啡师第一次跟练之后 | 轻滚小腿、恢复后可控坐站；不追痛、不排乳酸 |

支持鼠标/触摸拖拽、点选配对、先观察门槛、错配解释、音效开关、重玩、自由选关、前两关姿态对比、第 3–10 关对应动作示意。每关都有肌肉名称、位置、作用、可能机制、资料链接和适用边界。全部 22 个肌肉介绍条目附简化解剖位置图、观察方向与颜色图例，可点图放大，并查看分层说明及解剖参考。第 3–10 关以健身知识为核心，包含动作插画、步骤、原理与注意事项；工位和搬举建议仅保留在工作补充提示中。第十关结束可查看学习总结；完成记录仅保留在本次页面会话中。第 6–10 关每关含两道不计通关分的误区判断题，先判断再看解释；Cocos 学习卡同步为图文辨别页。

## 立即运行

在项目根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8766/preview/`。支持 `?level=1` 至 `?level=10` 直达。

浏览器版不需要安装前端运行依赖。JSON 需要 HTTP 读取，不能直接双击 HTML。此地址只在本机可用，不是公开发布地址。

## 项目结构

- `preview/`：已可玩的十关浏览器原型与科普卡。
- `assets/resources/data/levels.json`：浏览器与 Cocos 共用内容配置。
- `assets/resources/art/`：十位角色、职业工位与行动工具的透明插画。
- `assets/resources/audio/`：四种本地短音效。
- `assets/scripts/GameRoot.ts`：同步十关数据、交互、分页学习卡的 Cocos 组件。
- `assets/scripts/core/RecoverySession.ts`：可独立测试的观察、配对和计分逻辑。
- `docs/CONTENT_RULES.md`、`docs/LEVEL_AUTHORING.md`：后续内容制作与验收规范。
- `docs/levels/`：第 6–10 关逐关设计、文案、来源与验收记录。
- `docs/ITERATION_08.md`：本轮新增五关的范围与验收。
- `docs/ART_PROMPTS_06_10.md`：内置生图提示词及素材制作记录。
- `docs/COCOS_SETUP.md`：Creator 导入与微信验证说明。

## 自动化检查

```sh
npm ci
npm test
npm run test:browser
```

浏览器测试需要 Chrome，可用 `CHROME_PATH` 指定可执行文件。自动启动临时服务器，截图保存在系统临时目录。测试覆盖十关状态、素材与科普字段、两种操作顺序、观察门槛、错配、重复、取消、切关延迟、学习卡、最后总结及 320/390/933/1440 像素布局。

## 发布边界

目前是完整的十关浏览器试玩原型，不是已上线的微信小游戏。仓库仍未包含完整 Creator 工程设置、启动场景及微信构建产物。Cocos 脚本通过 TypeScript 语法检查，但未在 Creator 引擎内运行或微信真机测试；浏览器验收不能代替这些检查。

身体示意与变化为游戏表达，不用于诊断或治疗。
