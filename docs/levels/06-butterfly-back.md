# 第 6 关：蝴蝶背，不是健康勋章

## 场景与主知识

人物：小禾 / 拍完一组照片。
摄影师小禾刷到“背骨越明显越好看”。 她想先弄明白：肩胛应该被夹死，还是能自在地动？
唯一主知识：审美词蝴蝶背不能等同翼状肩胛；肩胛需要协调滑动，不是全天夹死。

## 核心玩法

先观察两条线索，再匹配两个练习；顺序不限，每项 50 分。误区选项不计分，解释后可重试。正确反馈显示对应静态动作，不表现为治愈或美体前后对比。

### 目标 A：肩胛 · 向前

线索：小禾想认识向前推时，肩胛如何沿胸廓滑动。线索是“手掌推开墙面”，不是把背骨挤出来。
操作：靠墙推撑。
正确反馈：推撑方向选对：前锯肌参与肩胛控制，不需要把肩胛夹死。
错配解释：本关这条线索学向前推撑；划船学向后拉，并非划船对肩膀毫无作用。

### 目标 B：肩胛 · 向后

线索：另一条线索是手肘贴近身体向后拉，再慢慢回去。目标是认识划船控制，不是全天挺胸夹背。
操作：轻阻力划船。
正确反馈：划船方向选对：拉回和放回都要可控，动作练习不等于日常一直夹背。
错配解释：本关这条线索学轻阻力划船；推撑关注另一种运动方向，不是两种练习只能练一块肌肉。

### 干扰项

全天夹紧肩胛。
这是本关的健身误区：肩胛要随手臂运动，不是全天夹紧或故意让背骨翘起。推与拉练习不同方向；明显单侧突出并伴疼痛或无力时，先专业评估。

## 学习卡

问题：蝴蝶背和翼状肩胛是一回事吗？
摘要：不必让肩胛骨成为审美成绩单。先认识能推、能拉、能随手臂协调运动的肩胛。
机制：“蝴蝶背”是审美用语，不是临床诊断。肩胛边缘显眼可能与体型、角度等有关；医学上的翼状肩胛涉及肩胛位置或运动改变，原因也不只有肌肉弱。正常抬手需要肩胛参与，全天夹死并不是本关的训练目标。

### 前锯肌

胸廓侧面，延伸到肩胛骨内侧。帮助肩胛贴着胸廓并向上旋转；不是只靠“夹背”就能替代它。
解剖图：anatomy-serratus.png；侧面 · 肋骨与肩胛。
前锯肌的肌束像锯齿沿胸廓侧面排列，连接肋骨和肩胛骨内侧；不是腹部斜肌。
解剖参考：[位置/层次](https://www.ncbi.nlm.nih.gov/books/NBK545241/)。

### 菱形肌 / 中、下斜方肌

肩胛骨之间及上背部。参与肩胛骨的位置控制，帮助上肢运动时保持协调。
解剖图：anatomy-scapular-group.png；背面 · 分层展示。
图中一侧移开斜方肌露出菱形肌，另一侧展示中、下斜方肌；它们不是同一层的肌肉。
解剖参考：[位置/层次](https://www.ncbi.nlm.nih.gov/books/NBK534856/)。

### 靠墙推撑

认识轻负荷推撑中的肩胛活动，不把它当作翼状肩胛治疗。
1. 面向稳固墙面，双掌约肩高，双脚站在可控距离。
2. 身体保持平稳，缓慢屈肘靠近墙，再舒适地推回。
3. 推回和返回都保持呼吸，不故意夹死肩胛，也不塌腰。
原理：推撑与划船是不同的运动任务，肩胛肌群协同参与，不是单肌肉开关。
注意：肩部急性损伤、术后、明显单侧突出伴无力或疼痛时先评估；手腕不适也不要硬撑。
素材：fitness-wall-push.png。

### 轻阻力划船

用舒适阻力学习上背控制；不是追求背骨突出。
1. 先确认弹力带完好、固定点稳固，阻力要容易控制。
2. 手肘靠近身体，慢慢向后拉，颈部保持舒适。
3. 慢慢放回，不猛弹、不为了夹背过度挺腰。
原理：中下斜方肌等参与划船，肩胛不只需要回收，也需要其他运动方向。
注意：固定点不可靠就不使用；不朝脸弹回。疼痛、麻木、无力时停止，不用游戏替代康复评估。
素材：fitness-band-row.png。

## 两道判断题

背骨越突出，就说明体态越健康。
结论：需要纠正。外形不是功能测试。“蝴蝶背”不能自动等同健康或翼状肩胛，后者需要专业评估。

肩胛骨需要随着手臂运动，而不是一直夹住。
结论：更接近事实。肩胛运动是上肢协调的一部分。要关注舒适活动、控制和症状，而不只盯着一张背部照片。

## 证据与不能推出的结论

翼状肩胛可能涉及肌肉、神经或其他问题。推撑和划船不是对突出肩胛的自诊或通用治疗；源资料支持运动/评估区别，不支持外貌判病。
