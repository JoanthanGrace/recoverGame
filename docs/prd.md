# 《打工人康复指南》MVP PRD v1.1

更新日期：2026-10-05。目标平台：微信小游戏。原始 v1.0 保留在 `prd-v1.0.md`。

## 原文内容总结

原文定位为极简医学解谜与科普小游戏。主循环是观察人物的体态问题、识别肌肉状态、拖拽对应工具、得到正向反馈、结算时复习知识并分享。

竖屏布局包括顶部标题/进度/提示、中部人物与肌肉热区、底部工具栏。唯一详细定义的内容关卡是第一关「键盘侠的觉醒」：

- 久坐人物含胸、头部前倾。游戏将胸大肌设为紧张目标，将后背菱形肌设为无力目标。
- 筋膜球配胸前：放松反馈，+50%。弹力带配后背：强化反馈，+50%。
- 错配不计分，轻微抖动并返回。非目标释放返回。
- 完成后锁定操作，展示科普和微信分享。
- 原文要求舒缓/升级/错误音效，以及肩膀打开、姿态舒展的分步变化。
- 「下一位病人」在原文仍是占位；没有第二、第三关的详细设计。

## 本次优化原则

1. 延续用户已认可的米色/墨绿轻漫画美术，不改为写实医学图。
2. 保留第一关两组配对，补齐肌肉名称、0/50/100% 进度、分步姿态和音效。
3. 进度叫「关卡进度」，表示游戏目标完成情况，不表示真实健康评分。
4. 成功文案叫「目标完成/舒展一点」，分享不使用未经统计的「第 X 个神医」。
5. 两项目标可任意顺序完成；中间姿态是通用插画反馈，不模拟真实治疗过程。
6. 每次成功都解释为什么匹配，错配说明当前目标需要什么，非目标不扣分。
7. 音效可开关；静音、加载失败或不支持音频不能影响通关。
8. 正式微信分享配图、Creator 场景和真机验证仍属于后续发布工作，不标记为完成。

## 第一关生成规格

### 画面与素材

同一小周角色，侧面朝右、固定服装和比例。复用现有开始/完成插画，新增一张中间舒展状态。工具为筋膜球、弹力带。文字由代码渲染，不写入人物图片。

胸前标记为红色闪烁，标注「胸大肌 · 需要放松」；背后标记为蓝色，标注「菱形肌 · 需要强化」。示意不承担精确解剖定位。

### 判定和反馈

| 操作 | 进度 | 图像与目标状态 | 音效 |
| --- | --- | --- | --- |
| 筋膜球 → 胸前 | +50% | 胸前标记完成、停止闪烁；首项成功显示中间姿态 | 短舒缓声 |
| 弹力带 → 后背 | +50% | 后背标记完成、点亮；首项成功显示中间姿态 | 轻升级声 |
| 工具错配 | 不变 | 解释原因、轻微抖动、工具返回 | 轻错误声 |
| 非目标/取消触摸 | 不变 | 返回，无处罚 | 无 |
| 两项都完成 | 100% | 完成姿态，约 1.3 秒后结算 | 完成短音 |

重复已完成目标不能重复计分。重玩恢复进度、目标、人物和音效播放状态。

### 科普与结算

提示说明本关两种肌肉状态与工具映射。结算复习「本关紧张区域放松、无力区域强化」，展示开始/完成对比，并提供下一关、重玩、分享。

## 执行与验收

配置的唯一运行来源为 `assets/resources/data/levels.json`，浏览器与 Cocos 共用。新素材放入 `assets/resources/art/`，音效放入 `assets/resources/audio/`。

先检查文档与配置一致，再用自动化检查目标覆盖、计分总和、素材、反馈文案与操作流程。浏览器通过后才能进入 Creator/微信验证；浏览器可玩不等于微信可发布。

## 用户方向补充与后续迭代（2026-10-05）

受众扩展为不同工种的普通劳动者。核心学习目标为：理解日常工作姿势/任务可能如何影响身体、认识具体肌肉名称与功能、了解改善的大概方向。

每关采用「职业场景 → 观察 → 肌肉与机制 → 改善行动 → 三层科普」结构，包含非办公室场景。完整内容规范见 `CONTENT_RULES.md`，候选关卡见 `LEVEL_ROADMAP.md`。

本补充优先于旧版中「所有问题都简化为一紧一弱」的生成倾向。原始第一关保留作玩法入门，但需增加胸大肌/胸小肌和肩胛功能组的白话科普，并清楚区分圆肩与胸椎驼背的概念。第二关保留习惯主题，不强行替它编造肌肉紧弱结论。

内容规则已经定义；展开科普卡、职业字段与后续新交互尚未实现。下一轮先落实已有两关科普，再细化一个非办公室场景。
