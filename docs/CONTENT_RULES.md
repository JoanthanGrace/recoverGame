# 后续关卡内容规则 v1.1

依据：2026-10-06 用户纠正的产品方向。适用对象为普通劳动者，包括办公室及非办公室工种。职业是场景，肌肉与健身知识是主角。

## 产品目标

让没有健身背景的玩家通过日常工作场景理解：持续姿势或习惯为何可能引起局部酸累、涉及哪些肌肉、如何认识合适的放松器械、轻柔拉伸或主动练习。游戏帮助认识健身知识，不根据职业、外观或酸痛主诉作个体诊断。

关卡不是职业病诊断，也不统一套用「一块紧、一块弱」；具体机制和解决思路必须与选题对应。

## 必须完成的学习链

职业任务 → 持续姿势/重复动作/负荷 → 局部感受与身体线索 → 相关肌肉及功能 → 选择器械或动作 → 学习步骤、原理与禁忌 → 通关复习。

每关结束后，普通玩家应能回答三个问题：

1. 这个人物的哪种工作习惯需要注意？
2. 涉及的肌肉在哪里、大致负责什么？
3. 这件器械或这个动作怎么尝试、为什么、什么时候不能继续？

## 每关五条内容规则

### 1. 先有真实场景

描述具体任务，而不是只贴职业标签。例如理发师为顾客处理头发时持续抬手、收银员在柜台反复伸手、司机长时间保持坐姿。

画面或线索必须体现动作、持续程度或环境设置。相同工种不等于每个人都会出现相同体态。

### 2. 保留专业肌肉名称，但配白话

每关主讲 2–4 个肌肉或功能组，避免把整个解剖表塞进界面。

展示格式为「肌肉名 + 位置/任务」。第一关补充科普可涉及胸大肌、胸小肌，以及中下斜方肌、菱形肌、前锯肌等肩胛控制相关肌肉；主界面只显示当前目标，更多名称进入科普卡。

名称的作用是解释机制，不用名称装饰画面。不涉及紧弱机制的习惯关也应说明相关组织为何承担负荷；不把持续坐着直接等同于某肌肉必然缩短或无力。

### 3. 用可能机制，不写绝对因果

可用「可能涉及」「与……有关」「本关简化为」。不得用「这种职业一定会」「看到圆肩就说明……」「只要练一块就能治好」。

圆肩侧重肩胛/肩部位置，驼背还涉及胸椎形态；不把两者当成同一个诊断。姿势、活动量、工作负荷、肌肉功能及个体差异可能共同影响表现。

### 4. 当前核心是健身，职业改进只作补充

- 核心配对优先使用筋膜球、泡沫轴、弹力带或无需器械的拉伸、活动、控制与训练动作。
- 放松、拉伸和主动练习要区分目的，不能把滚压等同于强化，也不能把酸痛等同于无力。
- 工位、推车、减负等工效学内容可放在折叠的工作提示中或未来独立扩展，不占据当前核心目标。

每关选择两个有区分度的肌肉/动作知识点。工具不表示必须购买；操作正确表示理解了游戏目标，不表示已经放松或治愈。不同方法可能有重叠作用，错配解释只说明当前教学目标，不能编造互斥疗效。

可展示大概的行动类别及目的。具体动作、次数、负荷、关节角度等新增细节，需另行核对来源，不能仅凭 AI 生图决定。

### 5. 科普分三层呈现

| 层级 | 内容 | 初始篇幅目标 |
| --- | --- | --- |
| 操作反馈 | 当前选择为什么匹配/不匹配 | 1 句话 |
| 通关摘要 | 生活原因、肌肉名、改善方向 | 约 60–100 字 |
| 可展开科普卡 | 肌肉位置/作用、机制、方法目的、适用边界、资料来源 | 约 180–300 字 |

篇幅是设计目标，可按阅读测试调整。默认结算保持简短，专业内容主动展开，不强迫玩家读长文才能继续。

## 游戏设计规则

- 每关只围绕一个主问题，使用 2–3 个目标；默认首版仍以 2 个目标验证。
- 正确选择须由已展示的线索推导，不要求玩家事先背肌肉名。
- 按内容选择身体观察、器械/动作配对或动作排序；环境调整不作为当前职业关的主玩法。
- 每个干扰项必须解释为什么不满足当前目标，不能宣称它在所有情况下都无用。
- 正确选择后显示对应动作示意，保持同一人物和服装；允许为看清动作换视角，不表现为即时治愈。
- 错误不惩罚知识薄弱的玩家，给可理解的原因和重试机会。
- 所有工种平等呈现，不把体态、体重或职业作为羞辱笑点。

## 内容审查与来源

机制、肌肉功能、改善方向各自记录来源，不用一篇泛泛文章替所有关卡背书。优先官方职业健康资料、医疗机构科普、原始研究；研究结果写明适用人群与范围，不扩大成所有人的规律。

每条关键主张记录：原文支持什么、游戏怎样简化、还不能推出什么。待核实的机制可以进入候选库，不能标记为已验证关卡。

## 第一关科普示例（下一轮 UI 待接入）

### 通关摘要草案

长期伏案时，肩膀和头部可能持续保持向前的位置。胸大肌、胸小肌及肩胛周围肌肉的功能都可能与肩部姿态有关。改善不只是松胸、练背，也要关注肩胛控制、工作设置和活动变化。

### 展开卡草案

胸大肌位于胸前，参与上臂活动；胸小肌位于更深层，与肩胛位置有关。中下斜方肌、菱形肌和前锯肌共同参与肩胛的稳定或运动，不能把它们统称为一块「背肌」。

研究发现，胸小肌较短的人在抬臂时可能表现出不同的肩胛运动；针对部分上交叉体态人群的训练研究，也关注肩胛相关肌肉功能。这说明「胸前活动度 + 肩胛控制」是值得学习的方向，不说明所有圆肩都由胸肌紧张造成。

本关把学习任务简化为放松和强化两种选择。现实改善还应结合工作姿势变化、环境调整及个人情况，游戏插画变化不代表治疗结果。

## 已核对的基础资料

- [Borstad & Ludewig：胸小肌长度与肩胛运动，2005](https://pubmed.ncbi.nlm.nih.gov/15901124/)：健康受试者组间比较，支持关联/可能机制，不证明职业或圆肩的单一原因。
- [肩胛稳定训练随机试验，2021](https://pubmed.ncbi.nlm.nih.gov/34151819/)：特定上交叉体态女性样本，肩部与胸椎指标不能等同看待。
- [肩胛/颈部肌肉训练随机试验，2019](https://pubmed.ncbi.nlm.nih.gov/30928841/)：研究包含中下斜方肌、前锯肌等肌肉指标，不能把单一肌肉效果推广到所有人。
- [HSE：工作相关肌肉骨骼问题](https://www.hse.gov.uk/msd/msds.htm)：多种任务、工作环境与组织因素可能参与风险。
- [NIOSH：人体工学风险因素](https://www.cdc.gov/niosh/ergonomics/ergo-programs/risk-factors.html)：风险与用力、重复、姿势及持续程度相关。
- [NIOSH：工作中持续站立](https://www.cdc.gov/niosh/bulletin/2014/standing.html)：用于久站候选题的活动变化方向，不用于认定某人的肌肉紧弱。

## 生成前检查

职业场景、主问题、观察线索、肌肉白话、机制依据、改善路径、操作与错配解释、三层科普、素材状态、验收项均填写后，才进入关卡制作。

本规则已用于当前五关的观察、行动和可展开科普卡。第六关及以后仍须逐关核对新任务与资料，不自动视为已实现。
