# 第一关运行与 Cocos 导入

## 浏览器试玩

无需引擎，在项目根目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，访问 `http://127.0.0.1:8765/preview/`。

支持鼠标/触摸拖拽，也支持「点击工具 → 点击区域」。错误不扣分；同一区域不会重复计分。两项可按任意顺序完成。通关后有姿态对比、重玩和分享降级提示。

## Cocos Creator

本仓库是资源与脚本集合，目前不是完整的 Creator 工程。

1. 在 Creator 3.x（建议先用 3.8 系列验证）创建空白 2D 工程。
2. 导入 `assets/scripts/` 和 `assets/resources/art/`，等待编辑器生成资源 `.meta`。
3. 新建场景，保留 Canvas、UI 摄像机。在 Canvas 下建立空节点 `GameRootNode`，位置设为 `(0, 0, 0)`。
4. 将 `GameRoot.ts` 挂在 `GameRootNode`，不要挂在含有其他业务内容的节点上。
5. 代码采用 720 × 1280、SHOW_ALL 适配。保存场景，将其设为启动场景，预览。
6. 四张 PNG 应以 Texture2D 资源可加载的方式导入，路径为 `resources/art/`；组件运行时创建 SpriteFrame。若出现「图片待导入」，检查控制台、资源类型和路径。

Cocos 脚本采用明确的 UI_2D 层级，只创建自己的子根节点，不删除 Canvas 摄像机。弹窗阻挡底层触摸；单一触点控制拖拽；取消触摸不会判定成功。中文作为本次 MVP 的主语言，旧多语言文件暂保留，当前新版 UI 不使用它们。

## 必须验证的交互

- 筋膜球 → 胸前：50%；弹力带 → 后背：100%。交换操作顺序也能通关。
- 错配不加分，工具返回；非目标释放不加分。
- 重复操作已完成区域不重复计分。
- 取消触摸、第二根手指、弹窗打开时不误触计分。
- 完成后人物切换，约 1.3 秒后结算；重玩恢复所有区域、工具和进度。
- 分享不可用的提示显示在结算面板内。
- 小屏和长屏没有关键按钮裁切，真机拖拽区域没有坐标偏移。

## 微信构建

待 Creator 场景验证通过，再配置真实 AppID，构建微信小游戏，并在开发者工具与真机验证。当前微信分享只提供中文标题和 query，未完成正式分享卡片图片接入，不把 API 调用当作分享成功。

本次未验证 Creator 场景渲染、微信构建、真机或正式发布。

## 第二关导入补充

这次请一并导入整个 `assets/resources/`，包括 `data/levels.json` 和第二关的四张 PNG；仅导入 art 会导致关卡加载失败。

组件启动时读取共同 JSON，顶部可切换两关。第二关有三张行动卡和观察门槛，请额外验证：未查看线索的拖拽不计分、干扰选项不计分、重玩恢复未观察状态，以及切换关卡时旧结算不会延迟出现。

浏览器版现在需要通过 HTTP 服务器打开，不能直接双击 index.html。测试说明见 `docs/ITERATION_02.md`。

## PRD 对齐补充

重新导入完整 `assets/resources/`，包含新中间姿态与 `audio/` 下四个 WAV。组件加载音频失败时保持关卡可玩；头部有音效开关。

请验证任一目标先完成都显示中间姿态，两个目标完成后切换到完成姿态；重玩回到起始状态。导航和下一关名称由配置自动生成。

## 五关更新说明

当前共用数据已扩展至 01–05，GameRoot 的数字导航可进入五关，每关学习卡有机制、肌肉、行动与资料四页。将完整 `assets/` 导入 Creator，不能只复制旧的第一关配置。新增职业插画同在 `resources/art/`。

学习卡资料按钮使用外部链接，需在目标平台验证可用性；微信环境若不允许打开网页，应改为平台允许的阅读方式，不影响关卡配对。浏览器的最后学习总结是预览端功能，Cocos 当前末关可返回第一关；两端共用科普内容，不宣称原生端已通过验收。
