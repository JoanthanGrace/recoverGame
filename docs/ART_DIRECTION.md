# 第一关美术方向

这次先优化现有关卡，不增加内容关卡。目标是让玩家清楚看到「伏案人物 → 区域选择 → 科普反馈 → 舒展对比」。

## 视觉语言

- 米色纸面、墨绿文字、赤陶色衣服、鼠尾草绿裤子。
- 深色轮廓的轻漫画角色，温和表情，清楚的侧面视角。
- 同一角色、同一服装、同一朝向的伏案与舒展两种姿态。
- 图片只承担人物与工具表达，标题、提示、目标、按钮由代码渲染，方便调整。
- 红色表示本关紧张目标，蓝色表示本关无力目标，文字同时表达状态，避免只依赖颜色。

## 素材

| 文件 | 用途 |
| --- | --- |
| `assets/resources/art/patient-before.png` | 伏案姿态 |
| `assets/resources/art/patient-after.png` | 完成后的舒展姿态 |
| `assets/resources/art/fascia-ball.png` | 筋膜球工具 |
| `assets/resources/art/elastic-band.png` | 弹力带工具 |

由图像生成工具一次生成同风格素材表，再按实际内容边界拆分为四张透明 PNG。人物导出 320 × 720，工具导出 256 × 256。它们是卡通示意，不作为准确的医学解剖图。

原始生成文件保留在生成工具目录。现有仓库没有查到旧图片，因此本次未覆盖或删除旧图片。
