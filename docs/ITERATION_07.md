# 迭代 07：学习卡与关卡提示细节

日期：2026-10-06。

## 界面

- 学习卡、解剖放大图等弹窗采用细窄的鼠尾草绿滚动条、透明轨道和圆角滑块。保留键盘、触控与鼠标滚动，强制颜色模式回退系统配色。
- 保留人物区域的拱形轮廓，将状态标签移到顶部中央安全区域，避免圆角裁切文字。五关均覆盖小屏与桌面检查。
- 第三至五关分别显示抬手肩颈酸累、久站小腿足底酸紧、搬运臀部酸累的状态，而不是相同口号。

## 误区辨别

第三个选项不是推荐动作，而是检验玩家能否辨别健身误区。去掉提前透露答案的“误”标记，用问号、“辨”和“判断：适合本关吗？”明确它的问答性质。说明文字提醒选项包含误区，选后解释。

新增可选字段 `tools[].wrongFeedback`。浏览器和 Cocos 在误区匹配时展示该选项专属解释；其他错误匹配仍展示目标原有提示。选择误区不增加进度。

## 验证

自动检查配置、素材、五关完成流程、误区反馈、学习卡滚动、解剖图放大与返回。状态标签在 320、390、933、1440 像素宽度下检查实际命中区域，避免拱形裁切。另检查固定桌面和手机截图。
